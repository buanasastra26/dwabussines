# DWA Legalitas

Website statis DWA Legalitas, siap deploy ke Hostinger.

## Isi website
- index.html: beranda
- layanan.html: layanan lengkap dan formulir konsultasi WhatsApp
- testimoni.html: testimoni perusahaan
- assets/: gambar website

## Deployment
Letakkan seluruh isi repository di document root website (public_html). index.html harus berada langsung di document root. Tidak diperlukan npm, build, database, atau environment variable.

Formulir menyiapkan pesan WhatsApp dan tidak menyimpan data di server.
